# Export Scripts

This directory contains retained export scripts and shared helpers used to assemble manuscript source-data exports and validation summaries.

The scripts reference derived analysis outputs through sanitized placeholders such as `<analysis_outputs>`, `<detect_results>`, and `02_exports`. The large exported data products are not included in this repository; see `data_manifests/` for sanitized manifest records.

These scripts are preserved as manuscript-specific archival code, not as a one-command public pipeline.
